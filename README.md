# 🎯 JAX77 HUNTER - واجهة Termux الفخمة

## 📖 الوصف
واجهة متكاملة ومتطورة لـ Termux مع إمكانيات تخصيص غير محدودة، مصممة خصيصاً لمحبي الأمان والجمال في التصميم.

## ✨ المميزات
✅ واجهة ترحيبية ثلاثية الأبعاد  
✅ 7 أنماط خطوط مختلفة  
✅ 7 ألوان قابلة للتخصيص  
✅ نظام حماية بكلمة مرور  
✅ حفظ الإعدادات تلقائياً  
✅ عرض معلومات المطور بتصميم فاخر  
✅ تكامل كامل مع Termux  

## 🚀 التثبيت السريع

```bash
# 1. استنساخ المستودع
git clone https://github.com/JAX77/JAX77.git

# 2. الدخول للمجلد
cd JAX77

# 3. منح صلاحيات التنفيذ
chmod +x install.sh

# 4. تشغيل التثبيت
./install.sh
```

📚 الاستخدام

بعد التثبيت، قم بتشغيل:

```bash
python ~/.hunter/hunter.py
```

## 📦 هيكلية التنصيب النهائية

```bash
# 1. إنشاء مجلد المستودع
mkdir JAX77 && cd JAX77

# 2. إنشاء الملفات
touch install.sh hunter.py login_system.py config.json README.md

# 3. نسخ المحتوى لكل ملف كما هو أعلاه

# 4. منح الصلاحيات
chmod +x install.sh
chmod +x hunter.py
chmod +x login_system.py

# 5. رفع للمستودع
git init
git add .
git commit -m "إطلاق JAX77 Hunter - الواجهة الفخمة"
git branch -M main
git remote add origin https://github.com/JAX77/JAX77.git
git push -u origin main
